# Toolkit

一个在浏览器内运行的开发者工具箱。

- JSON 格式化、压缩和语法校验，保留数字原值。
- 粘贴数据库里的字段值后点「解码并格式化」，支持 JSON 字符串及去掉最外层引号的转义对象或数组。此操作会展开值本身是 JSON 对象或数组的字符串。
- JSON Diff，按字段路径显示差异，对象忽略键顺序，数组按索引比较。
- 文本比较，左右对照并高亮行内变化。支持忽略大小写、忽略空白（包括空行）和只显示差异。
- Unix 时间戳与日期互转，支持秒、毫秒、UTC 和北京时间。
- Unicode 转码，支持文本与 Unicode 转义、文本与数字引用互转。「文本转数字引用」按原始输入编码，例如 `\u` → `&#92;&#117;`。数字引用支持十进制（`&#65;`）和十六进制（`&#x41;`）解码。
- 二维码提取，支持选择本地图片或在二维码页按 Ctrl+V（Mac 上按 ⌘+V）粘贴图片或截图，然后预览、识别并复制原始内容。每张图返回一个二维码结果，网址以文本显示。

## 本地运行

在浏览器中打开 `index.html`。也可以在项目目录运行 `python -m http.server 4173 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:4173/`。

Unicode 转码和二维码识别均在浏览器中离线运行。离线打开时请保留完整项目目录。二维码识别使用随项目分发的 [jsQR 1.4.0](https://github.com/cozmo/jsQR)，许可证见 [Apache 2.0](assets/vendor/jsqr/LICENSE)。图片在本地读取。

## 发布到 GitHub Pages

提交这些静态文件后，在仓库的 **Settings → Pages** 选择 **Deploy from a branch**，发布对应分支的 `/(root)`。
